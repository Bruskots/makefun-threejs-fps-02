Dustline Yard — a round-based tactical FPS in three.js. You and three bot teammates attack two bombsites against four Jackal bots on an original three-lane desert yard: plant the charge on site A or B or wipe out the enemy team, earn money each round, and spend it in the buy menu on rifles, SMGs, shotguns, a scoped sniper, frag grenades and armour. Headshots pay, stopping to aim pays, and the first team to 5 rounds takes the match — with a live minimap, killfeed and fully synthesised sound, all running offline from static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
